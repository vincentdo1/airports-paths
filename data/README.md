# Data

The airport and route data in this project is derived from the **OpenFlights**
airport and route database.

- Source: https://openflights.org/data.html
- License: the OpenFlights airport and route data is made available under the
  Open Database License (ODbL). See the OpenFlights site for the current terms and
  attribution requirements.

## Files

- `airports.csv`, `routes.csv` — raw OpenFlights extracts.
- `cleaner.py` — turns the raw CSVs into the whitespace-separated node/edge files.
- `nodes500.txt` / `edges500.txt`, `nodes1000.txt` / `edges1000.txt` — the 500 and
  1000 busiest airports and the routes among them; the server and offline tools use
  these.
- `nodes.txt` / `edges.txt` — a small sample used by the unit tests.

## Format

- Node files: `CODE latitude longitude` (one airport per line).
- Edge files: `EDGEID source destination` (one directed route per line).

The precomputed betweenness centrality served by the `/network/central-airports`
endpoint lives in `results/` and is regenerated by `main.cpp`.
